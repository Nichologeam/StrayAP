# StrayAP
Archipelago client implimentation for Stray built on [lua-apclientpp](https://github.com/black-sliver/lua-apclientpp).

This mod requires the [experimental version of UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/experimental-latest), and has only been tested to work on the Windows Steam version of Stray. Your mileage may vary on other versions.

## Installing
1. Download the latest UE4SS experimental release.
2. Navigate to your Stray files. This can be done by right-clicking the game in your Steam Library, hovering over Manage, and selecting Browse Local Files.
3. Navigate to Hk_project > Binaries > Win64
4. Unzip UE4SS inside this folder so `dwmapi.dll` is inside the Win64 folder.
5. Navigate to the mods folder (Mods or ue4ss > Mods depending on version) and unzip the Latest StrayAP Release into that folder.
6. Start Stray. Follow the onscreen instructions to connect.
